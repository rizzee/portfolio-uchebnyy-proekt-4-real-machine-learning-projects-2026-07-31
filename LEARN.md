# LEARN.md

## 1. Что сделали
- Создали Python-проект с 4 практическими примерами ML:
  - Анализ тональности текста
  - Детекция спама
  - Рекомендательная система
  - Прогнозирование временных рядов
- Реализовали CLI-интерфейс для запуска примеров
- Подготовили тесты и sample-датасеты

## 2. Что разобрать (концепции)
- Feature extraction в NLP (TF-IDF, Bag of Words)
- Метрики качества классификации (accuracy, precision, recall)
- Коллаборативная фильтрация для рекомендаций
- ARIMA для временных рядов
